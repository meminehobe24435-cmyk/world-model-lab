# Benchmark 结果

所有数字都由 `python -m wm.bench.run_benchmark` 生成，原始 JSON 在 `runs/base/benchmark_*.json`。
**本页结论只在本项目的简化场景内成立**，不要外推到真实机器人数据。

## 实验设置

| 项 | 值 |
| --- | --- |
| 观测 | 48×48（RGB / 深度 / 语义） |
| 场景 | 4 方块 + 遮挡墙 + 目标区，随机布局 |
| 训练数据 | 200 回合 / 11,552 步（专家 110 + 随机 50 + 扰动 40） |
| 留出数据 | val 23 回合（未见布局）、hard 23 回合（目标区更远） |
| 反事实 | 155 对（前缀一致、后缀动作不同） |
| 模型 | 1.64M 参数：VAE(z=96) + 3 层动作条件 Transformer + 多任务头 |
| 训练 | CPU，40 epoch，约 12 分钟 |
| 评测 | 20 条 rollout × 16 步；MPC 16 个布局 × 48 步 |

---

## 1. 主结果（`base`，val 留出布局）

### 重建与空间一致性 —— 这一块很好

| 指标 | 值 | 说明 |
| --- | --- | --- |
| `depth_mae` | **0.0070** | 归一化深度上的平均绝对误差 |
| `occupancy_iou` | **0.987** | 解码深度与真值深度的占据 IoU |
| 训练末 RGB L1 | 0.0077 | 图像重建 |
| 训练末语义 CE | 0.0101 | 语义分割重建 |

解码器几乎完美复现了观测 —— 但**这不等于世界模型好**，见下。

### 动力学准确性 —— 瓶颈在泛化，不在动力学

| 指标 | 值 |
| --- | --- |
| `err_t0`（**表征天花板**） | **0.184 m** |
| `err_t1` | 0.187 m |
| `err_t8` | 0.201 m |
| `err_t16` | 0.228 m |
| `ade` / `fde` | 0.204 m / 0.228 m |
| `degradation_ratio`(t16/t1) | 1.24 |

**关键读法**：`err_t0` 是第 0 帧的位置误差，而第 0 帧的潜在来自**真实观测的编码**、
不含任何预测成分。它高达 0.184 m，而误差曲线到 t16 只涨到 0.228 m（1.24 倍）。

也就是说：**误差几乎全部来自"表征/泛化"，不是来自"多步 rollout 发散"。**
模型在**训练布局**上把状态头练到了 0.0004 的 MSE（每维 RMSE ≈ 0.02 m），
但换到**未见布局**就退化到 0.13 m/维。训练集只有 200 个布局，状态头记住了布局
而没有学会"从图像里读位置"。

这个判据（把 t0 误差单列出来）是本项目最有用的一个诊断量：
如果只看 `ade` 一路涨，很容易误判成"动力学不行"，而去加动力学层数 —— 那治不了病。

### 物体持久性

| 指标 | 值 |
| --- | --- |
| `visible_err` | 0.187 m |
| `occluded_err` | 0.206 m |
| `occlusion_penalty` | **1.32** |

遮挡墙后面的方块在图像里可见像素为 **0**，但误差只比可见时高 32%。
说明潜在表示确实在**维持不可见物体的状态**，而不是每帧重新从图像里读 ——
这是"物体持久性"最直接的证据。

### 失败模式分桶

| 桶 | 位置误差 |
| --- | --- |
| 有接触 `contact_err` | 0.216 m |
| 无接触 `no_contact_err` | 0.201 m |

接触阶段误差略高（+7%），符合预期：接触是动力学最非线性的部分。

### 动作可控性（反事实配对，155 对取 40 对）

| 指标 | 值 | 读法 |
| --- | --- | --- |
| `divergence_corr` | **0.380** | 预测分歧与真值分歧正相关，方向学对了 |
| `sensitivity_ratio` | **0.963** | 预测分歧 / 真值分歧 ≈ 1 → **敏感度标定准确** |
| `action_vs_zero_ratio` | 0.457 | 见下方说明 |

`sensitivity_ratio ≈ 0.96` 是本项目**最正面**的一个数字：给两条不同的动作序列，
模型预测出的状态差异幅度与真实世界的差异幅度几乎一致（0.0571 vs 0.0594）。
说明动作**确实**通过动力学传播成了状态变化，幅度也没有系统性偏差。

`action_vs_zero_ratio = 0.46 < 1` 需要解释：它比较的是"两条不同动作之间的分歧"
与"某条动作 vs 全零动作的分歧"。小于 1 说明"动作序列 vs 全零"的差异比"两条真实动作
之间"的差异更大 —— 这其实是合理的（全零序列在分布外），但它作为"模型是否对动作敏感"
的判据并不好用，所以主判据用 `sensitivity_ratio`。

### 任务量预测

| 指标 | 值 |
| --- | --- |
| `dist_mae` | 0.188 m |
| `dist_corr` | −0.160 |

**任务头基本没学会**：预测的目标距离与真值几乎不相关（甚至轻微负相关）。
这是下面 MPC 失败的直接原因。

## 2. 下游任务收益：潜空间 MPC（**负结果**）

| 策略 | 成功率 | 平均末距 | 平均步数 |
| --- | --- | --- | --- |
| **MPC（世界模型 + CEM）** | **0 / 16 = 0%** | 0.448 m | 48.0 |
| random（随机动作） | 0 / 16 = 0% | 0.435 m | 48.0 |
| scripted（带特权 GT 的脚本专家） | **5 / 16 = 31.3%** | 0.146 m | 44.0 |

**世界模型驱动的规划没有跑赢随机动作。**

这是必须如实写出来的负结果。诊断：

1. `dist_corr = −0.16` —— 规划器的打分函数（任务头预测的目标距离）本身没有信息量，
   于是 CEM 的精英筛选接近随机。
2. `err_t0 = 0.184 m` 说明状态头在未见布局上定位不准，即使改用状态头打分也救不回来。
3. `roll`（多步潜 rollout）损失停在 0.12 不再下降，6 步规划视界已经超出模型可靠范围。

也就是说：**规划失败的第一因是表征泛化，不是规划算法。** 想修，顺序应该是
先扩布局多样性 → 再提状态头泛化 → 最后才是加长规划视界 / 换更好的打分函数。

## 3. 泛化：hard 留出布局

| 指标 | val | hard |
| --- | --- | --- |
| `err_t0` | 0.184 | 0.177 |
| `ade` | 0.204 | 0.177 |
| `occupancy_iou` | 0.987 | 0.989 |
| `occlusion_penalty` | 1.32 | 1.26 |
| `dist_corr` | −0.16 | +0.27 |

hard 布局（目标区被刻意放到更远处）的数值反而略好。原因是 hard 分片的**动作分布更集中**
（专家推动距离更长、更规律），位置方差更小。这说明当前瓶颈不在"任务难度"，
而在**布局多样性**。

## 4. 消融：三种典型的"世界模型退化"

> ⚠️ **口径**：消融各训练 15 epoch，主模型 40 epoch，所以**绝对数值不可直接横比**。
> 但下面三条结论都是**定性**的（是否对动作敏感、表征是否坍缩），与训练轮数无关。

| 变体 | `dyn`↓ | `sensitivity_ratio` | `divergence_corr` | `ade`↓ | 诊断 |
| --- | --- | --- | --- | --- | --- |
| **base** | 0.070 | **0.96** | **+0.38** | 0.204 | 正常：动作敏感且标定准确 |
| `no_action` | 0.059 | 2.09 | +0.30 | **0.184** | 动作条件被去掉后**过度敏感** |
| `gru` | **0.420** | **0.004** | −0.01 | 0.253 | **忽略动作**：输出与动作无关 |
| `vq` | **0.0004** | ∞ | +0.17 | 0.258 | **码本坍缩**：所有输入映射到同一个码 |

三条都值得展开：

### 4.1 `gru`：动力学退化成"输出常量"
把 Transformer 换成 GRU，`dyn` 损失从 0.070 涨到 0.420（6 倍），
`pred_divergence_mean` 掉到 **0.00013**（base 是 0.0571）——
**给任何动作，模型都预测几乎同一个潜在**。

于是它的 `ade`（0.253）比 base 差，但更关键的是它作为世界模型**没有用**：
不能回答"换一个动作会怎样"。这正是 JD 里说的"要关注模型是否理解动作因果"。

### 4.2 `no_action`：ade 更低，但可控性崩了
把动作在训练时置零，`ade` 反而**更低**（0.184 < 0.204）—— 因为潜在不再随动作漂移，
状态估计一直贴着初始值，反而"稳"。但 `sensitivity_ratio` 冲到 **2.09**：
模型把动作差异放大成了过大的状态差异。

**这条消融的价值在于提醒：`ade` 这类"预测误差"指标单独看会骗人。**
一个"什么都不预测、永远输出初值"的模型可能在这类指标上很好看。
所以动作可控性必须单列成指标 —— 这正是 JD 强调"评估视觉质量之外的"的意义。

### 4.3 `vq`：码本坍缩，动力学"完美"但表征死了
VQ 变体的 `dyn` / `roll` 损失低到 **0.0004 / 0.0005**，看起来碾压 base。
但看 `gt_divergence_mean`：**0.0** —— 两条不同动作支路的真值潜在**完全相同**。

原因：码本坍缩了。所有输入都被编码到同一个码字，于是"预测下一个潜在"变成
"预测同一个常量"，误差自然接近 0，下游状态头却从 0.0004 退化到 0.0092（23 倍），
`ade` 也是最差的 0.258。

**教训**：`dyn` 损失接近 0 不是好消息，是危险信号。必须同时看
`gt_divergence_mean`（真值潜在是否还有区分度）与状态/重建侧指标。
表里 `sensitivity_ratio = 1.9e7` 这种离谱数字本身就是坍缩的指纹。

## 6. 诚实的结论

**做到了**：可交互 3D 场景 + 完整 GT 的数据管线；动作条件潜在动力学模型；
按"动作可控性 / 动力学准确性 / 空间一致性 / 长期预测 / 物体持久性 / 泛化 / 失败模式 /
下游收益"八个维度的系统评测；三项消融且都给出了机制解释。

**没做到**：跨布局的状态泛化（`err_t0 = 0.184 m`）；任务头基本没学会（`dist_corr = −0.16`）；
因此潜空间 MPC **没有跑赢随机动作**，更没跑赢脚本专家。

**下一步优先级**（按性价比排序）：
1. 扩布局多样性（200 → 数千），这是当前第一瓶颈；
2. 状态头换成空间 soft-argmax / 热图回归，而不是从全局池化向量回归坐标；
3. 任务头用更强的监督（密集的 distance-to-goal 标签）；
4. 最后才考虑加长规划视界与换 CEM 变体。
